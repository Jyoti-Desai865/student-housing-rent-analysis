# Pune Student Housing Rent Analysis

## Project Overview
This project analyzes rental housing data to understand rental prices, locality-wise affordability, furnishing trends, and bachelor-friendly housing options in Pune.

## Objectives
- Analyze average rent across localities.
- Calculate average rent per square foot.
- Compare furnished and unfurnished rental properties.
- Identify affordable localities for 1-bedroom properties.
- Compare locality-wise rent with the overall dataset average.
- Explore bachelor-friendly rental options.

## Tools and Technologies
